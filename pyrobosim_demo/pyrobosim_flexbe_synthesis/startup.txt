## Notes

* Set up system in FlexBE config to match the launch mode (for example `p0_full_spec_demo`).
* Goals are string arrays: pass each predicate as a separate element.
* Full-spec pipelines encode their goals in YAML; request goal overrides only affect capability pipelines.
* Typical capability goal example: `bread0=3` and `butter0=3`.


## Goal Override Examples

Goals use `string[]` — pass each predicate as a separate array element:

* P0 capabilities system:
  `clear; ros2 run pyrobosim_flexbe_synthesis request_synthesis --ros-args -p system_name:=p0_capabilities_demo -p goals:='["bread0=3", "butter0=3"]'`
* Parsed p0 capabilities system:
  `clear; ros2 run pyrobosim_flexbe_synthesis request_synthesis --ros-args -p system_name:=p0_capabilities_parsed_demo -p goals:='["bread0=3", "butter0=3"]'`
* Parsed p1 capabilities system:
  `clear; ros2 run pyrobosim_flexbe_synthesis request_synthesis --ros-args -p system_name:=p1_capabilities_parsed_demo -p goals:='["bread0=3", "butter0=3"]'`
